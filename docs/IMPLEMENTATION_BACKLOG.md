## Reduce scope

Keep SSH, isolation, FUSE for v1, Redis state, SQLite outbox, PostgreSQL evidence, one console, deterministic rendering and optional AI preparation. Three stores have distinct roles; their count alone does not establish waste.

Defer legacy cron/apt/user/log-aging plugins, Layer 0 integration, HTTP/Telnet, public operations, arbitrary execution, expertise scoring, AI session summaries, cloud services and Home distribution. Monitoring profiles remain optional.

After measurements, consider unifying simulation paths and metrics, incremental summaries and a virtual-filesystem interface behind which FUSE could be replaced. Check dependencies before removing code/assets. Preserve existing local changes.
