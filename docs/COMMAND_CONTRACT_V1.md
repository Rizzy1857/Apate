# Mirage command contract v1

This is the complete participant command surface for the Research MVP. Mirage emulates this bounded subset; it does not promise Bash, GNU coreutils or POSIX compatibility. Anything not listed is unsupported and must fail rather than execute on the host.

## Grammar and limits

- UTF-8 input is limited to 65,536 bytes, 512 parser tokens and 64 pipelines per submission. A NUL byte is invalid.
- Supported composition is `;`, `&&`, `||` and `|`. Pipelines are sequential byte-buffer transformations, not concurrent processes. The status is the last stage status; stderr is not piped.
- Single quotes are literal. Double quotes permit `$NAME` expansion. Backslash quotes the following character. Expansion supports `$NAME` only; unset names become empty.
- Supported redirects are `<`, `>`, `>>`, `2>` and `2>>`. They are opened left to right before the command effect. Descriptor duplication, here documents/strings and process substitution are unsupported.
- Command substitution, globbing, tilde expansion, background jobs, subshells, functions, aliases and host process execution are unsupported.
- Output and file-fed input are each bounded at 1 MiB. Exceeding a bound returns nonzero without returning partial generated output.
- Parser rejection is a malformed/unsupported request. Registry status `127` means blocked or unknown command. Other nonzero statuses mean a recognized command failed or used an unsupported option. Status `0` means only that the emulated operation completed.

Interactive EOF closes the session. `Ctrl-C` cancels the current input line when handled by the SSH loop; there is no job/process-control model. `exit` is an interactive session control word, not a registry command. Exec, subsystem and forwarding SSH requests are outside the shell grammar and receive separate structured request outcomes.

## Commands

`--` is supported only where stated. A filename beginning with `-` is otherwise not addressable in v1.

| Command | Supported operands/options | Result/effect |
|---|---|---|
| `cd` | zero or one path | Changes virtual `PWD`; default is `HOME` |
| `pwd` | none | Prints virtual `PWD` |
| `export` | zero or more `NAME=VALUE`; protected identity/path names are immutable | Sets session variables |
| `unset` | zero or more valid names; protected names are immutable | Removes session variables |
| `env`, `printenv` | none | Prints the complete bounded session environment |
| `echo` | arbitrary operands; options have no special meaning | Joins operands with spaces and adds newline |
| `whoami`, `hostname` | none | Prints configured profile identity/host |
| `id` | zero/one user and one of `-u`, `-g`, `-G`, optionally combined with `-n` | Prints profile user/group data |
| `uname` | none or exactly `-a` | Prints fixed profile kernel information |
| `free`, `top`, `ss`, `df` | none | Prints bounded profile/world state |
| `ps` | none, `aux`, `-aux`, `-e` or `-ef` | Prints bounded synthetic process state |
| `ls` | zero/one path; `-a`, `-l`, `-la`, `-al` | Lists one path; no recursion or color |
| `cat` | zero or more files; optional leading `--` | Concatenates files, or stdin with no files |
| `find` | zero or one path | Recursively lists that tree; no predicates |
| `grep` | optional `--`, literal substring pattern, zero or more files | Selects matching lines; stdin when no file |
| `head`, `tail` | optional `-n` nonnegative integer, optional `--`, zero or more files | Selects complete lines; stdin when no file |
| `stat` | one or more paths, no options | Prints bounded file metadata |
| `touch` | one or more paths, no options | Creates or updates files |
| `mkdir` | optional leading `-p`, then one or more paths | Creates directories |
| `rm` | leading combinations of `-r`/`-f`, optional `--`, then one or more paths | Removes files; directories require `r` |
| `rmdir` | one or more paths, no options | Removes empty directories |
| `cp` | optional leading `-r` or `-R`, then exactly source and destination | Copies one file or tree |
| `mv` | exactly source and destination | Moves one file or tree |

`bash`, `sh`, Python interpreters, Perl, Ruby, PHP, `curl`, `wget`, Netcat and Socat are deliberately blocked and return `127`. Every other unlisted command also returns `127`. Downloading, executing binaries and reaching external systems are not Research MVP features.

## Evidence interpretation

A submission records intent. Each recognized execution has a correlated result carrying its command identity, exit status, generated byte count, locally transport-accepted byte count and delivery certainty. Filesystem effects are separate correlated events. Results preserve every executed pipeline stage's status/byte counts and explicitly mark conditional pipelines skipped by `&&` or `||`. A successful final pipeline stage therefore does not erase an earlier failure.

The machine-readable reference matrix is `tests/fixtures/command_contract_v1.json`; `tests/validation/test_command_contract_matrix.py` executes its 107 named cases and verifies unique identities plus coverage of all 30 declared handlers. `tests/validation/test_command_contract.py` separately exercises grammar, redirects, limits, traversal and compound-stage semantics. Real SSH/FUSE cases supplement these fixtures; they do not silently broaden this contract.
